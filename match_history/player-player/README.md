## How this folder is used

Files named YYYYMMDD-HHMM.txt contain one match's moves, undo events where supported, and final result. A numeric suffix distinguishes matches saved in the same minute. These files are generated by chess_app.match_history and ignored by Git; this README is retained. The log is intended for reading, not loading a saved game. Existing files may reflect older logging behavior.
